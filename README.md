## API عمومی ادزیتو

API نسخهٔ ۱ برای اتصال سرویس‌های داخلی، داشبوردهای اختصاصی و اتوماسیون تبلیغات طراحی شده است.

~~~text
Base URL: https://adsito.online/api/v1
Authorization: Bearer <api_key>
Content-Type: application/json
~~~

کلید API در [بخش مدیریت کلیدها](https://app.adsito.online/settings/api-keys) ساخته می‌شود، به فضای کاری دسترسی دارد و فقط از IPهای مجاز پذیرفته می‌شود. پاسخ‌ها JSON هستند، مبلغ‌ها به تومان برمی‌گردند و خطاها در قالب Problem Details شامل کد پایدار و `traceId` ارائه می‌شوند. دامنهٔ کلید API عمداً محدود است و همهٔ عملیات تعاملی پنل را در اختیار کلید قرار نمی‌دهد.

### گروه‌های اصلی API

| سرویس | نمونه مسیرها | کاربرد |
| --- | --- | --- |
| تبلیغات | `GET /ads`، `POST /ads`، `POST /ads/{id}/submit` | ساخت، مشاهده و کنترل چرخهٔ تبلیغ |
| هدف‌گیری | `GET /targeting/resolve`، `POST /targeting/select` | شناسایی مقصد و اعتبارسنجی مخاطبان |
| قیمت | `GET /rates/minimums`، `POST /rates/quote` | دریافت حداقل‌ها و پیش‌فاکتور کوتاه‌مدت |
| آمار | `GET /stats/overview`، `GET /ads/{id}/stats` | گزارش فضای کاری و عملکرد هر تبلیغ |
| خروجی | `GET /exports/ads.xlsx`، `GET /exports/ads/{id}/report.pdf` | دریافت Excel و PDF |
| کیف پول | `GET /wallet`، `GET /wallet/ledger` | مشاهدهٔ موجودی و گردش مالی |

### نمونه درخواست

~~~bash
curl 'https://adsito.online/api/v1/ads?page=1&pageSize=20' \
  -H 'Authorization: Bearer <api_key>'
~~~

برای عملیات مالی مانند ثبت نهایی یا افزایش بودجه، از `Idempotency-Key` مطابق مستندات استفاده کنید تا تکرار درخواست باعث اجرای دوباره نشود.

**CTA توسعه‌دهندگان:** [مرجع کامل API و نمونه‌های cURL](https://adsito.online/docs) · [ساخت و مدیریت کلید API](https://app.adsito.online/settings/api-keys)

## شفافیت و محدودیت‌ها

- ادزیتو خرید عضو یا فروش و رشد کسب‌وکار را تضمین نمی‌کند.
- تبدیل‌های داخل مقصد، مانند عضویت، شروع ربات یا خرید، لزوماً توسط ادزیتو اندازه‌گیری نمی‌شوند.
- هر تبلیغ ابتدا در ادزیتو و سپس مطابق فرایند Telegram بررسی می‌شود؛ نتیجه و زمان انتشار تضمین‌شده نیست.
- بودجهٔ مصرف‌نشده به کیف پول داخلی برمی‌گردد و برداشت بانکی موجودی کیف پول ارائه نمی‌شود.
- ادزیتو مستقل است و وابستگی یا نمایندگی رسمی از Telegram ندارد.
